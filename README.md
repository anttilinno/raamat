## Editing

Edit the `.md` files. They are Obsidian-flavoured Markdown — `[[wikilinks]]`
between the files, `> [!note]` callouts, and a paragraph shaped like

    **SISE. RESTORAN — ÕHTU** · *beat: maailm*

as a screenplay slug line. GitHub renders everything except the wikilinks,
which is why this file carries plain links as the index.

New chapter? Link it here, and add its filename to the chapter list in
`.github/workflows/pages.yml` if it should reach the published page too.

## Publishing

Pushing to `main` renders the chapters with pandoc into one page and deploys
it to GitHub Pages — see `.github/workflows/pages.yml`. This needs Pages to be
switched on once by hand: **Settings → Pages → Source: GitHub Actions**. Until
then the book reads here, straight from the Markdown.
